Reading a Residual Plot

After you fit a line, the leftovers are the most useful thing on your screen. A handful of shapes tell you almost everything that can go wrong with the fit.

A residual is the vertical gap between a point and the fitted line: measured y minus fitted y. Plot the residuals against the fitted value, and again in the order you took the data, and look for shape. Healthy residuals are a flat, even band around zero. All data here is simulated, so the true model is known.

Make these plots yourself (Excel, MATLAB, Python) 
' Excel (data in A = x, B = y, rows in the order you took them)
F1  =SLOPE(B:B, A:A)          F2  =INTERCEPT(B:B, A:A)
C2  =$F$1*A2 + $F$2           fitted value, fill down
D2  =B2 - C2                  residual, fill down
Scatter D against C (shape, spread), then D against row number (run order).

% MATLAB
mdl = fitlm(x, y);
plotResiduals(mdl, 'fitted')          % shape and spread
figure; plot(mdl.Residuals.Raw, 'o')  % run order
plotDiagnostics(mdl, 'cookd')         % single points

# Python
import numpy as np, matplotlib.pyplot as plt
b1, b0 = np.polyfit(x, y, 1)
fitted = b0 + b1 * x
resid = y - fitted
plt.scatter(fitted, resid); plt.axhline(0)   # shape and spread
plt.figure(); plt.plot(resid, "o")           # run order (keep data in the order taken)

What to take away

  1. Make the same three checks after every fit: residuals against the fitted value, residuals in run order, and a look for single points that stand out.
  2. Read them in order: shape first (a wrong shape fakes the other patterns), then spread, then time order, then single points.
  3. Healthy is boring: a flat, even band around zero with no shape. Anything else is a clue, not a verdict. Check the notes from the session before changing the model.
  4. A clean residual plot still can't catch everything. Noise in your x readings and unmeasured drift can bias the slope and leave the residuals looking fine. That's Module 5.

The four patterns

A bend

Wrong shape. Fit the model the physics gives you.

A fan

Uneven scatter. The line is fine; the error bars aren't. Module 3.

A trend in run order

Something changed during the session. Module 4.

One point far away

Check the notes, then check its influence. Don't just delete it.
